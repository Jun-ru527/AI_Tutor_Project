# 核心接口约定（V1.1）
## 6个核心字段
1. amount（金额）：数字
2. category（分类）：文字（支出：餐饮/交通/购物/居住/娱乐/医疗/其他；收入：工资/兼职/红包/理财/其他）
3. spent_at（时间）：文字（YYYY-MM-DD）
4. merchant（商户）：文字
5. note（备注）：文字
6. type（收支类型）：文字（收入 / 支出）

## 对外函数约定
- ai_core.py 提供 `parse_text(text)` 和 `parse_image(image_path)`
- db.py 提供 `add_bill(data)`, `list_records()`, `sum_by_category()`, `get_budget()`, `get_ai_logs()`
